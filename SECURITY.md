# Security Policy

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/LuthienResearch/luthien-proxy/security/advisories/new), not in a public issue, pull request or discussion.

Include what you found, the affected version or commit, and steps to reproduce it. A proof of concept helps.

## Supported versions

Security fixes are made on `main` and ship in the next release.
